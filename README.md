### 🚀 Task 1: Static Landing Page (NovaFlow)
- **Objective:** Build a visually polished static landing page for a modern SaaS/Workflow product (`NovaFlow`).
- **Tech Stack:** HTML5, CSS3 (No JavaScript required).
- **Features:**
  - Sticky glassmorphism navigation with mobile hamburger menu.
  - Compelling hero section with CTA buttons and pure CSS dashboard mockup.
  - 5 distinct content sections: Features, About Us, How It Works, Transparent Pricing, and Testimonials.
  - Multi-column footer with contact details and social media placeholder links.
  - Fully responsive across desktop, tablet, and mobile devices.

---

### 🌟 Task 2: Personal Portfolio Website
- **Objective:** Create a personal digital résumé showcasing skills, projects, and contact info.
- **Tech Stack:** HTML5, CSS3.
- **Features:**
  - Hero profile section with professional photo, role (*Software Developer*), and social badges.
  - About Me narrative detailing background and problem-solving focus.
  - Categorized technical skills grid (Frontend, Core Programming, Dev Tools).
  - Featured Projects with direct Live Demo links and GitHub code:
    - **E-Government Portal:** [Live Demo](https://e-goverance-portal.vercel.app/)
    - **Karmayog Studio Portfolio:** [Live Demo](https://piyush-portfolio-w1vk.vercel.app/)
  - Direct contact cards (Email, LinkedIn, GitHub) and styled message form.
  - Pure CSS smooth scroll navigation and desktop/mobile responsiveness.

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/ritikakumarigupta/OIBSIP.git
   ```
2. Navigate into any task folder:
   ```bash
   cd OIBSIP/WebDev-L1-LandingPage
   # OR
   cd OIBSIP/WebDev-L1-Portfolio
   ```
3. Open `index.html` in your web browser or use VS Code Live Server.

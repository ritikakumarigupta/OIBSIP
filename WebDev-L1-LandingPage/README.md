## 📌 Project Overview
**NovaFlow** is a visually polished, high-conversion static landing page built for a modern SaaS & Workflow Automation Platform. Designed from the ground up to establish foundational HTML5 semantic markup and advanced CSS3 layout techniques.

The landing page showcases a cohesive modern dark-indigo branding, responsive navigation, engaging product feature grids, workflow process breakdowns, transparent pricing plans, and client testimonials.

---

## ✨ Feature Checklist Fulfilled

- [x] **Sticky / Fixed Navigation Bar**:
  - Sticky glassmorphism header with brand logo (`NovaFlow`), 5 navigation links (*Features*, *About Us*, *How It Works*, *Pricing*, *Testimonials*), and action CTAs.
  - Mobile-responsive hamburger menu implemented with pure CSS (no JavaScript required).

- [x] **Hero Section**:
  - Compelling headline: *"Supercharge Your Workflow With Intelligent Automation"*.
  - Descriptive subheadline outlining the value proposition.
  - Call-to-action buttons (*"Start 14-Day Free Trial"* & *"Explore Features"*).
  - High-impact dashboard mockup card and trusted customer brand tickers.

- [x] **Distinct Content Sections (5 Sections Included)**:
  1. **Features Section:** 6 responsive cards highlighting core platform capabilities with custom SVG icons.
  2. **About Us Section:** Company story, reliability stats (99.99% uptime, 120M+ tasks), and comparative visual showcase.
  3. **How It Works Section:** 3-step numbered workflow breakdown from connection to automated scaling.
  4. **Pricing Plans Section:** 3 transparent tiers (*Starter*, *Pro Team - Popular*, *Enterprise*) with feature checklists.
  5. **Testimonials Section:** Social proof cards featuring 5-star ratings, quotes, and client profiles.

- [x] **Call to Action (CTA) Banner**:
  - High-conversion pre-footer banner with input field and trial kickoff.

- [x] **Footer with Placeholder Contact & Social Links**:
  - Multi-column footer with brand statement, product links, company information, contact details (`support@novaflow.io`), live system status pill, and social links (Twitter/X, GitHub, LinkedIn, Discord).

- [x] **Consistent Colour Palette**:
  - Unified design tokens utilizing deep navy/dark slate background (`#070b14`), electric blue (`#3b82f6`), vibrant purple (`#8b5cf6`), and emerald green accents.

- [x] **Fully Responsive Layout (Desktop & Mobile Usability)**:
  - Built using CSS Flexbox and CSS Grid.
  - Seamlessly adapts across all screen widths: Desktop (1200px+), Tablet (< 992px), and Mobile Phones (< 600px).

- [x] **No Element Overlap**:
  - Strict global `box-sizing: border-box`, explicit padding, margins, and non-collapsing flex/grid containers.

- [x] **Clean, Readable Typography**:
  - Modern Google Fonts (*Plus Jakarta Sans* & *Poppins*) with distinct heading versus body scale.

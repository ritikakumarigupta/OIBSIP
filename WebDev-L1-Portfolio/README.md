## ✨ Features & Checklist Fulfilled

- [x] **Profile / Hero Section**:
  - Displays developer name, role (*Software Developer*), and a professional photograph (`profile.jpg`).
  - Eye-catching introductory headline, status indicator, and quick CTA buttons.
  - Direct social link badges for GitHub, LinkedIn, and Email with SVG icons.
  - Viewport-balanced height and spacious layout to prevent crowding.

- [x] **About Me Section**:
  - Concise narrative outlining technical background, problem-solving mindset, and software development interests.
  - Feature highlights illustrating web development focus, algorithmic problem-solving, and goal orientation.

- [x] **Skills Section**:
  - Visual categorized grid showcasing technical proficiency across:
    - **Frontend:** HTML5, CSS3, JavaScript, Responsive Design, Flexbox & Grid, Modern UI/UX.
    - **Programming & Core:** C/C++, Java, Data Structures, OOP Concepts, Algorithms.
    - **Tools & Platforms:** Git, GitHub, VS Code, Vercel Deployment, Web Standards.

- [x] **Projects Section**:
  - Integrated direct **Live Demo** buttons (pointing to Vercel hosted apps) and **GitHub Code** buttons.
  - Project cards include tech stack pills, summary descriptions, and modern visual badges.

- [x] **Contact Section**:
  - Direct contact cards for Email, LinkedIn profile, and GitHub.
  - Fully styled interactive contact form (Name, Email, Subject, Message).

- [x] **Smooth Scrolling & Navigation**:
  - Sticky glassmorphism header with logo and navigation links.
  - Pure CSS smooth scroll navigation (`scroll-behavior: smooth`) with scroll padding.

- [x] **100% Responsive for Desktop & Mobile Phones**:
  - Pure CSS responsive hamburger menu for mobile phones.
  - Generous spacing (`padding: 120px 0`), flexible grids, and touch-friendly buttons on mobile.

## 💻 How to Run Locally

1. Clone or download this repository to your local machine:
   ```bash
   git clone https://github.com/ritikakumarigupta/WebDev-L1-Portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd WebDev-L1-Portfolio
   ```
3. Open `index.html` directly in any web browser (Google Chrome, Firefox, Edge, etc.):
   - Simply double-click `index.html`, OR
   - Right-click `index.html` and select **Open with Live Server** in VS Code.

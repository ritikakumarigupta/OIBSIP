# OISSIP - Temperature Converter Website (Level 1, Task 3)

## 🚀 About the Project
An interactive web utility tool that converts temperature values dynamically between Celsius, Fahrenheit, and Kelvin with real-time input validation and absolute zero edge-case handling.

### 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

### 📱 Features Checklist
- [x] Numeric input field with validation for non-numeric errors.
- [x] Unit selector dropdown menu (Celsius / Fahrenheit / Kelvin).
- [x] Convert button triggering instant mathematical calculations.
- [x] Result display area showing converted values across all units simultaneously.
- [x] Edge-case handling for absolute zero violations (e.g., below -273.15°C).
- [x] Clean, centered UI layout with clear labels.

### 📂 File Structure
- `converter.html` - UI layout structure.
- `converter.css` - Clean card design and form styling.
- `converter.js` - Conversion formulas and validation logic.
